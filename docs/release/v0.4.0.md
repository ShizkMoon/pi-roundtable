# Pi Roundtable v0.4.0 release notes

Status: Windows x64 personal-project alpha.

Pi Roundtable v0.4.0 is a Windows local-first personal-project alpha. The
shipped product is a self-contained Windows x64 application whose local Pi
Runtime Host owns model execution. Android remains a UI-only scaffold and is
not included in the Windows release assets.

## Highlights

- Private tool-approval events preserve both the direct host and acting role in
  their audience, matching the protocol and deterministic C++ reducer.
- Protocol and sync relay accept syntactically valid additive v1 event kinds;
  Windows persists the cursor and fails closed before projecting an unsupported
  kind.
- Windows validates visibility and audience before data reaches the C++ ABI.
- Provider, MCP, and sync endpoints reject credentials, query strings,
  fragments, non-loopback HTTP, and IPv4-mapped IPv6.
- The development sync server refuses unauthenticated startup and supports the
  optional PostgreSQL persistence path.
- Runtime Host dependency resolutions include `undici` 8.9.0 and Hono 4.12.34.
- Windows release assets include commit-bound metadata, dependency inventory,
  CycloneDX SBOM, third-party notices, and SHA-256 values.

## Release verification

The release candidate is built from a clean exact `main` commit. The required
gate runs the complete repository tests, default MSI ICE validation, and the
full self-contained payload through isolated install, launch, repair, major
upgrade, downgrade blocking, second repair, uninstall, and residue checks. The
publisher re-downloads and hashes the draft, final pre-publication, and public
assets.

This personal release is allowed to be unsigned. Its ECDSA-signed updater
manifest still binds the canonical GitHub URL, file name, size, SHA-256, version,
channel, and architecture. Windows may display an unknown-publisher or
SmartScreen warning when the MSI is opened.

## Compatibility and known limitations

- Public protocol remains v1 and the Windows meeting database remains schema
  v2. No automatic local-data downgrade is promised.
- A production-UpgradeCode stable-to-candidate run on a disposable clean VM and
  a real 96/144/192 DPI matrix are optional diagnostics and are not claimed as
  verified for this release.
- Android remote sync, E2EE, TLS termination, rate limits, retention jobs,
  multi-replica notifications, and push remain pending.
- The default sync Compose deployment uses in-memory storage; restarting it
  loses meetings, leases, and replay history.
