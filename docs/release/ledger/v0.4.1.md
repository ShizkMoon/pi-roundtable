# v0.4.1 release ledger

Ledger opened: 2026-08-05

Release state: candidate preparation

This is a personal-project release ledger. `verified` is reserved for evidence
bound to the final main commit and candidate bytes. Authenticode, a disposable
clean VM, and a three-DPI visual matrix are optional and do not block v0.4.1.

| Evidence | State | Current record |
| --- | --- | --- |
| Protected-main commit and CI | pending | The v0.4.1 version commit and its protected-main CI must complete before the local ReleaseCandidate gate. |
| Full release build and default ICE | pending | Requires a fresh `releaseEligible: true` ReleaseCandidate report from the exact clean main commit. |
| Full-payload isolated MSI lifecycle | pending | Requires install, launch, two repairs, major upgrade, blocked downgrade, uninstall, and no-residue evidence for the production payload. |
| Version, metadata and release materials | pending | The canonical five assets must be bound to version `0.4.1` and the release commit. |
| Draft/public re-download | pending | The publisher must verify local, draft, pre-publication, and public bytes. |
| Stable updater manifest | pending | The committed stable manifest intentionally remains bound to v0.4.0 until the public v0.4.1 MSI is re-downloaded and verified. |
| Authenticode | optional; not configured | The unsigned personal MSI may trigger Windows publisher warnings. If later enabled, trust and timestamp checks remain fail-closed. |
| Clean production VM / 96,144,192 DPI / real provider | optional; pending | Useful diagnostics, not v0.4.1 release requirements and not claimed as verified. |

## Required commands

```powershell
npm run quality:fast
npm run quality:windows
npm run quality:release-candidate
pwsh -File .\scripts\publish-windows-release.ps1 `
  -ReleaseCandidateReportPath <quality-gate-report.json> `
  -ReleaseNotesPath .\docs\release\v0.4.1.md `
  -Publish
```

The ReleaseCandidate command must report `releaseEligible: true`. A dirty
worktree, failed or skipped tests, skipped default ICE validation, mismatched
metadata, an incomplete full-payload lifecycle, or changed release bytes still
blocks publication.
