## Required final commands and evidence

```powershell
npm run quality:fast
npm run quality:windows
npm run quality:release-candidate -- -ExpectedSignerThumbprint <production signer> <production evidence arguments>
```

The release-candidate command must report `releaseEligible: true`. Ordinary CI, a dirty worktree, skipped ICE/test steps, an ephemeral signing certificate, or an isolated QA UpgradeCode lifecycle does not satisfy this ledger.
