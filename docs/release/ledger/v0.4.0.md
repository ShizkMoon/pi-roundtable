# v0.4.0 release ledger

Ledger opened: 2026-08-04

Release policy simplified: 2026-08-05

Candidate state: pending exact-main ReleaseCandidate run

This is a personal-project release ledger. `verified` is reserved for evidence
bound to the final main commit and candidate bytes. Authenticode, a disposable
clean VM, and a three-DPI visual matrix are optional and do not block v0.4.0.

| Evidence | State | Current record |
| --- | --- | --- |
| Protected-main commit and CI | pending final release commit | Record the exact main SHA and successful C++/TypeScript/Windows jobs after the policy PR merges. |
| Full release build and default ICE | implemented; final run pending | `quality:release-candidate` runs the normal verified build without skip/suppress switches and hashes the canonical five assets. |
| Full-payload isolated MSI lifecycle | implemented; final run pending | Required: install, two launches, two repairs, major upgrade, blocked downgrade, uninstall, no QA residue, production registration unchanged. |
| Version, metadata and release materials | implemented; final run pending | MSI metadata, dependency inventory, CycloneDX SBOM, third-party notices, source commit, sizes and SHA-256 must agree. |
| Draft/public re-download | implemented; execution pending | Publisher checks exact main/tag and verifies every asset locally, in the draft, immediately before publication, and after publication. |
| Stable updater manifest | ECDSA mechanism verified; v0.4 execution pending | Generate only from the verified public MSI; `authenticodeRequired` may be `false`. |
| Authenticode | optional; not configured | The unsigned personal MSI may trigger Windows publisher warnings. If later enabled, trust and timestamp checks remain fail-closed. |
| Clean production VM / 96,144,192 DPI / real provider | optional; pending | Useful diagnostics, not v0.4.0 release requirements and not claimed as verified. |

## Required commands

```powershell
npm run quality:fast
npm run quality:windows
npm run quality:release-candidate
pwsh -File .\scripts\publish-windows-release.ps1 `
  -ReleaseCandidateReportPath <quality-gate-report.json> `
  -ReleaseNotesPath .\docs\release\v0.4.0.md `
  -Publish
```

The ReleaseCandidate command must report `releaseEligible: true`. A dirty
worktree, failed/skipped tests, skipped default ICE validation, mismatched
metadata, an incomplete full-payload lifecycle, or changed release bytes still
blocks publication.
