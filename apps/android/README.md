# Android client

Native Kotlin/Jetpack Compose Material 3 client. It is intentionally UI-only: meeting state arrives from the sync service, while Pi and local tools remain on the authoritative desktop Runtime Host.

The sample screen is executable UI scaffolding, not a live backend connection. It demonstrates compact, medium, and expanded layouts plus an explicit interruption control.

Build requirements: JDK 17, Android SDK 37, and network access or a populated Gradle cache.
